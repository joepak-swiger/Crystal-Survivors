# Controls

| Input | Action |
| --- | --- |
| WASD / arrow keys | Move Cloud; movement updates his walk direction |
| Escape / P | Pause or resume |
| Mouse click / 1, 2, 3 | Choose a level-up card |
| Enter / Space | Start or restart |
| Controller left stick / D-pad | Move |
| Controller south button | Start or restart |

Attacks are automatic. Cloud swings at the closest enemy in range, facing toward the target independently of his movement direction. Browser scrolling is suppressed while gameplay keys are pressed.
